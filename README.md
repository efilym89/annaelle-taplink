# Annaelle Taplink

Самодостаточный taplink для Annaelle, опубликованный через GitHub Pages.

## Публикация

- Основная страница: `index.html`
- Рекомендуемый код для блока Tilda T123: `tilda-embed.html`
- Полная резервная версия для прямой вставки в T123: `tilda-inline-t123.html`

Публичный адрес:

`https://efilym89.github.io/annaelle-taplink/`

## Tilda

1. Добавьте блок `T123 — HTML-код`.
2. Вставьте содержимое `tilda-embed.html`.
3. Сохраните и опубликуйте страницу.

В редакторе Tilda блок может отображаться как код или заглушка. Проверять нужно на опубликованной странице.
